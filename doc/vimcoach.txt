1. INTRODUCTION                                               *vimcoach-intro*

vimcoach watches how you edit in Neovim (and VS Code via `vscode-neovim`) and
shows you shorter Vim motions for what you just did. It looks at your buffer,
cursor jumps, and before/after edits rather than just counting repeated keys,
and sticks to practical motions you'd actually use.

==============================================================================
2. COMMANDS                                                *vimcoach-commands*

                                                                   *:VimCoach*
:VimCoach [subcommand]
    Control vimcoach. Subcommands:
      dashboard  Open the stats dashboard (default)
      toggle     Pause or resume
      enable     Enable coaching
      disable    Pause coaching
      coach      Switch to Coach mode (hints only)
      strict     Switch to Strict mode (blocks key spamming)
      adaptive   Switch to Adaptive mode (blocks after repeated misses)
      status     Print a quick summary
      test       Trigger a sample hint
      reset      Clear saved stats

:VimCoachDashboard                                        *:VimCoachDashboard*
    Open the stats dashboard.

:VimCoachToggle                                              *:VimCoachToggle*
    Pause or resume vimcoach.

:VimCoachStrict                                              *:VimCoachStrict*
    Toggle strict mode on or off.

:VimCoachReset                                                *:VimCoachReset*
    Clear saved stats.

==============================================================================
3. CONFIGURATION                                             *vimcoach-config*

Call `require("vimcoach").setup(opts)` in your Neovim config: >lua

  require("vimcoach").setup({
    enabled = true,
    mode = "coach", -- "coach" | "strict" | "adaptive"
    cooldown_ms = 0,
    rule_cooldown_ms = 0,
    practical_only = true,
    ui = {
      style = "float",        -- "float" | "notify" | "echo"
      position = "top_right", -- "top_right" | "bottom_right" | "cursor"
      duration_ms = 4500,
    },
  })
<

==============================================================================
4. COACHING MODES                                             *vimcoach-modes*

- `coach` (default): Shows hints without blocking keys.
- `strict`: Blocks repeated `h`/`j`/`k`/`l` or arrow presses past the
  threshold while still showing hints.
- `adaptive`: Starts with hints only, then enables blocking for a habit once
  you miss it `adaptive_strict_misses` times.

==============================================================================
5. VS CODE (VSCODE-NEOVIM)                                   *vimcoach-vscode*

When running inside VS Code via `vscode-neovim` (`vim.g.vscode ~= nil`),
hints show up inline at the end of the line (hover for details) and briefly
in the status bar. Configure `vscode.style` (`"inline"`, `"inline_and_status"`,
`"status_bar"`, or `"toast"`).

==============================================================================
6. LUA API                                                      *vimcoach-api*

- `require("vimcoach").setup(opts)`
- `require("vimcoach").enable()` / `.disable()` / `.toggle()`
- `require("vimcoach").set_mode("coach"|"strict"|"adaptive")`
- `require("vimcoach").dashboard()`
- `require("vimcoach").statusline()` (for lualine/heirline)
- `require("vimcoach").get_summary()`
